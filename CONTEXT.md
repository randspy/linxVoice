# Language Learning

This context describes reusable scenarios for spoken language practice.

## Language

**Scenario**:
A reusable role-play setup for practising a target language at a specified proficiency level. It contains the setting, learner and AI roles, mission, opening line, and language goals for a future conversation.
_Avoid_: Conversation transcript

**Scenario idea**:
The learner’s initial description of the role-play they want, such as two magicians fighting an evil vampire.
_Avoid_: Scenario (for the initial idea alone)

**Target language**:
The language the learner chooses to practise in a scenario.

**Proficiency level**:
The learner-selected level that guides the scenario’s language difficulty and learning goals.

**Scenario draft**:
A generated scenario that the learner can preview and edit before explicitly saving it for later use.
_Avoid_: Saved scenario (before the learner saves)
